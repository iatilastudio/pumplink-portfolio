O produto

Quatro camadas, um sistema coeso

Um único código serve todas as lojas, roteadas por parâmetro de URL. Onboarding de novo cliente é criar um documento no Firestore — sem mexer no código.

Camada 1

Vitrine pública — o link-in-bio que vende

A loja no Instagram aponta para essa página. O cliente final vê catálogo completo, categorias, oferta da semana em destaque e aciona o WhatsApp direto do produto.

  • Tema claro/escuro configurável pelo dono
  • Categorias com ícones e filtro dinâmico
  • Oferta da semana com badge de desconto automático
  • Botão WhatsApp por produto para converter vendas
  • Horário de funcionamento com status ao vivo
  • Delivery, mapa e avaliações em ações rápidas
Vitrine ao vivo
Camada 2

Painel admin — o dono no controle

Dashboard completo para o lojista gerenciar tudo sem depender de ninguém. Status em tempo real, visão clara do estoque e alertas automáticos via WhatsApp.

  • Status aberto/fechado com horário automático
  • Contagem de produtos ativos, inativos e esgotados
  • Alertas de estoque — dispara WhatsApp quando o nível baixa
  • Upload de foto via ImgBB API ou busca via Pexels
  • Oferta da semana e categorias personalizáveis
Painel admin
Camada 3

Master admin — visão completa do negócio

Painel exclusivo para monitorar toda a operação: métricas financeiras, saúde das lojas, alertas automáticos e gestão de clientes em um único lugar.

  • MRR e ARR — receita mensal e anual estimada
  • Ticket médio por cliente ativo
  • Alertas automáticos — detecta lojas sem produto ou foto
  • Gestão de clientes com acesso direto à vitrine e painel
  • Onboarding de novo cliente sem alterar nenhum código
Master admin
Detalhe de design

Tema escuro — experiência premium no celular

A vitrine foi projetada para ser o link-in-bio do Instagram. No tema escuro, o design se destaca no feed e transmite credibilidade ao cliente final da loja.

  • Toggle claro/escuro — o dono da loja escolhe
  • Mobile-first — toda a navegação pensada para celular
  • Identidade visual com logo e cores próprias de cada loja
Tema escuro
Tecnologia

Stack enxuta, sistema robusto

Sem frameworks pesados. HTML, CSS e JavaScript puro com Firebase como backbone — dados, autenticação e deploy em uma plataforma só.

Firebase Firestore Firebase Auth Firebase Hosting HTML / CSS / JavaScript ImgBB API Pexels API WhatsApp API Multi-tenant por URL param

Roteamento multi-tenant sem backend customizado

Uma URL como vitrine.html?loja=jefferson-suplementos carrega os dados do cliente certo no Firestore. Zero código diferente por cliente — onboarding é criar apenas um documento.

Firestore compound queries e índices compostos

Filtros combinados (ex: ativo + ordem) exigem índices no Firestore. Aprendi a criar e gerenciar via console Firebase após depurar falhas silenciosas em produção.

Deploy seguro sem quebrar produção

Firebase Hosting com targeting explícito de projeto evita deploy no lugar errado. Cache do browser mascarava atualizações — janela anônima virou ferramenta padrão de teste.
